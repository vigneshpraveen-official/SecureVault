# SecureVault — Frontend

React 18 + Vite + Tailwind CSS v4 + Redux Toolkit + React Router + axios. See the root
`docs/guide.md` ("Daily run commands" and "Frontend module map") for setup, environment
variables, and architecture — this file is intentionally not a duplicate of that.

```bash
npm install
cp .env.example .env.local
npm run dev
```
